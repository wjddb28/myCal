    🟦 Google 캘린더 직접 연동

    구글 계정으로 로그인해서 일정을 가져오고, 이 앱에서 만든 일정을 올립니다. 반복·다중·기간 일정 모두 구글 형식으로 변환돼요.

    클라이언트 ID 발급 방법 (처음 한 번, 5분)
    1. Google Cloud Console에서 새 프로젝트 만들기
    2. API 및 서비스 → 라이브러리 → Google Calendar API 사용 설정
    3. OAuth 동의 화면 → 외부 → 테스트 사용자에 본인 구글 계정 추가
    4. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션
      승인된 JavaScript 원본에 http://localhost:5500 추가
    5. 발급된 클라이언트 ID를 위 칸에 붙여넣기
    구글 로그인은 file://로 연 파일에서는 동작하지 않아요. 폴더의 start.bat으로 실행하면 http://localhost:5500으로 열립니다.

    📱 아이폰 캘린더 · 미리알림

    이 앱은 아이폰 캘린더와 미리알림을 직접 사용해요. 여기서 만든 일정은 아이폰 캘린더에, 할 일은 미리알림에 바로 저장되고, 아이폰에서 바꾼 내용도 앱을 열 때마다 반영돼요.

    구글·노션 캘린더도 함께 보려면
    1. 아이폰 설정 → 앱 → 캘린더 → 캘린더 계정 → 계정 추가 → Google
    2. 그러면 구글 캘린더 일정이 이 앱에도 자동으로 나타나요. 카테고리로 구글 캘린더를 골라 저장하면 구글과 Notion 캘린더에도 들어가요.
    권한을 거절했거나 “추가만 허용”을 골랐다면 아이폰 설정 → 앱 → 나의 캘린더에서 캘린더와 미리알림을 전체 접근으로 바꾼 뒤 앱을 다시 열어 주세요.

    🍎 iCloud · 아이폰 캘린더

    아이폰·맥 캘린더(iCloud)에 있던 기존 일정을 한 번에 가져오고, 여기서 만든 일정을 아이폰으로 보냅니다. iCloud 캘린더(집·직장 등)마다 카테고리가 색 그대로 만들어져요.

    앱 암호 만드는 법 (애플 비밀번호와 달라요)
    1. Apple 계정 관리 페이지에 로그인
    2. 로그인 및 보안 → 앱 암호 → ＋ 눌러 이름(예: 나의 캘린더) 입력
    3. 나온 xxxx-xxxx-xxxx-xxxx를 위 칸에 붙여넣고 연결
    4. 아이폰 설정 → 내 이름 → iCloud → 캘린더가 켜져 있어야 해요
    앱 암호는 이 PC의 앱 폴더에만 저장되고 Windows 계정 암호화로 잠겨요. 필요 없어지면 “연결 해제” 후 애플 계정 페이지에서 앱 암호를 삭제하면 완전히 끊겨요.

    ⬛ Notion 캘린더

    Notion 캘린더는 구글 캘린더 계정을 연결해서 보여주는 앱이에요. 위에서 구글로 올린 일정은 Notion 캘린더에도 자동으로 나타나고, Notion 캘린더에서 만든 일정은 구글에서 가져오기로 받아올 수 있어요.

    설정 방법
    1. Notion 캘린더 → 설정 → 캘린더 계정에서 같은 구글 계정 연결
    2. 이 앱에서 “구글로 올리기” → Notion 캘린더에 바로 반영
    3. 구글 연동 없이 옮기려면 아래 ICS 파일을 구글 캘린더에 가져오기 하면 돼요.

    📄 ICS 파일 (구글·애플·아웃룩·노션 공통)

    로그인 없이 파일로 주고받아요. 구글 캘린더 설정 → 가져오기/내보내기에서 사용합니다.
